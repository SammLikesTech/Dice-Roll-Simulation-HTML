Dice Roll Simulation

A short program that waits for you to type ROLL, picks a number from 1 to 6, and tells you whether it was a high or low roll. Below is the original Python code, a C++ version that behaves the same way, and a demo you can try.

The two versions

dice.py
import random

Dice = 1,2,3,4,5,6,
Roll_dice = input("Enter ROLL to roll dice: ")

if Roll_dice.upper() == "ROLL":
    Dice = random.randint(1,6)
    print(Dice)
    if Dice >= 4:
        print("Wow a high roll :D")

    if Dice <= 3:
        print("Welp a low roll :/")

if Roll_dice.upper() != "ROLL":
    print("You spelt roll wrong >:C")
dice.cpp
#include <algorithm>
#include <cctype>
#include <iostream>
#include <random>
#include <string>

int main() {
    std::string rollInput;
    std::cout << "Enter ROLL to roll dice: ";
    std::getline(std::cin, rollInput);

    // Same job as Python's .upper()
    std::transform(rollInput.begin(), rollInput.end(),
                   rollInput.begin(), ::toupper);

    if (rollInput == "ROLL") {
        std::random_device rd;
        std::mt19937 gen(rd());
        std::uniform_int_distribution<int> dist(1, 6);

        int dice = dist(gen);
        std::cout << dice << "\n";

        if (dice >= 4) {
            std::cout << "Wow a high roll :D\n";
        } else {
            std::cout << "Welp a low roll :/\n";
        }
    } else {
        std::cout << "You spelt roll wrong >:C\n";
    }
    return 0;
}

Build and run the C++ file with g++ -std=c++17 dice.cpp -o dice && ./dice

What the program does

1. Read the input

It asks for text and converts it to upper case, so roll, Roll and ROLL all count.

2. Pick a number

If the text is ROLL, it picks a whole number from 1 to 6, each equally likely, and prints it.

3. Judge the roll

A 4, 5 or 6 prints the high roll message. A 1, 2 or 3 prints the low roll message.

4. Catch typos

Anything other than ROLL prints the spelling message and no dice is rolled.

Two small changes in the C++ version

The Python line Dice = 1,2,3,4,5,6, makes a tuple that is thrown away as soon as Dice is set to the random roll, so the C++ version leaves it out.

The three separate if checks in Python become one if / else in C++. The behavior is the same, and the program only tests the input once.
